参考面板与自动整理

摘要、设定建议、情节点、伏笔，以及后台整理全书。

参考面板

点顶栏的「参考面板」打开，可以「移到左侧 / 移到右侧」。共五个标签：

标签内容
本章一句话备注、设定建议、摘要与要点、当前阶段、出场设定、本章设定变化、已记下对白、逐段标记
设定正文里提到的设定卡
片段你收集的素材片段，可以在补全时手动附带
情节点本章脉络、提议情节点和本小节已有的情节点
伏笔全书伏笔，按未回收 / 已回收 / 弃用筛选

它会自己填什么

下面这些都在后台完成，不打断你写字。原则是：只往空处填、往末尾追加，不改你写的字；每次自动修改都能撤销。

内容何时更新你能做什么
摘要离开这一节，或保存后两分钟没再编辑自己写的摘要不会被覆盖
本章脉络随摘要一起整理，显示在「情节点」标签顶部；还没写的章，会按大纲和前几章提议情节点「加为情节点」或「不要这条」
设定建议有本章摘要之后别名和首次出场自动补上，新卡片由你点添加；可撤销
本章设定变化随摘要新事实追加到卡片末尾，可逐条移除
对白与说话人整理全书时点说话人标签修改
口癖、说话风格角色在足够多的小节里开口后改过之后就归你，不再被替换
逐段标记随摘要只作参考；伏笔由你决定是否加入列表

要点只由你自己写，AI 补全和起草情节点时会读。

整理全书

打开一本书约 10 秒后，NovelKit 会在后台依次给每章写摘要、整理对白与设定、整理逐段标记。左侧栏的模式按钮下会显示进度。

  • 你在打字时它会让路：「等你停笔半分钟后继续」。
  • 可以「暂停 / 继续整理全书」或「跳过这一章」；连续两次失败会自动暂停，点继续再试。
  • 「应用设置 → 模型 → 生成模型」里可以关掉「后台整理全书」或「自动生成摘要」。

伏笔

在「伏笔」标签「添加本章伏笔」，或在正文选中一句「标为伏笔」。每条显示埋下的章节、「N 章前」和原文引文；回收时点「在本章回收」。
