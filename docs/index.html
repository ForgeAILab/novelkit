快速开始

下载、安装、建一本书、写下第一章，再让补全帮你接着写。

NovelKit 是什么

NovelKit 是写给日更、几百章、一个人写的连载作者的桌面写作台。你只管写正文：停顿时它在光标后给出一行灰字，按 Tab 接受；摘要、设定卡、伏笔和情节点在旁边的参考面板里自己整理好。

  • 稿件就是文件。每本书是你电脑上的一个普通文件夹，正文和设定卡都是 Markdown，随时拿得走。
  • 停笔即保存。不用按保存，每一版都能找回。
  • AI 只帮忙，不代写。补全要你按 Tab 才进正文；自动整理只往空处填、往末尾追加，不会改你写的字，每次修改都能撤销。
  • 可以完全离线。自带本地模型引擎，补全和整理都能在你自己的电脑上跑。

1. 下载与安装

在 版本页 下载对应系统的安装包：

系统文件
macOS · Apple 芯片（M1 及以后）NovelKit_…_aarch64.dmg
macOS · IntelNovelKit_…_x64.dmg
Windows 10 / 11NovelKit_…_x64-setup.exe（或 .msi）
Linux.AppImage、.deb 或 .rpm

测试版没有签名。macOS 第一次打开时，在「应用程序」里右键 NovelKit →「打开」；如果仍提示已损坏，在终端运行 xattr -dr com.apple.quarantine /Applications/NovelKit.app。Windows 出现 SmartScreen 时点「更多信息 → 仍要运行」。

2. 新建一本书

  1. 打开 NovelKit，在欢迎页右侧点 「新建作品」。
  2. 填 「作品名」（必填），作者、系列和语言可以以后再改。
  3. 「位置」默认是 文稿/NovelKit（Windows 为 Documents\NovelKit），也可以点「选择位置…」换一个文件夹。「文件夹名称」会按作品名自动生成。
  4. 创建完成后选 「开始规划」先写大纲，或 「开始写作」直接写正文。

已经有稿子？在欢迎页「更多」菜单里选 「导入 DOCX / Markdown / TXT…」，把「标题 1/2/3」或分隔线 *** 对应到卷、章、小节，预览无误再导入。导入不会改动原文件。

3. 下载本地模型（可选，推荐）

不配模型也能写作、整理大纲和设定库；灰字补全和自动整理需要模型。最省事的是用自带的内置引擎：

  1. 打开 「更多 → 应用设置 → 模型」，找到「内置引擎（llama-server）」。
  2. 点 「下载基础模型」：一个补全模型、一个对话模型、一个决策模型，共约 4.7 GB。内存 24 GB 以上的电脑还可以「下载全部」，多一个约 5.7 GB 的大对话模型。
  3. 下载完成即可使用，补全、摘要默认就指向内置引擎。引擎只在本机运行，第一次请求时加载，闲置 10 分钟后自动释放内存。

想用 Ollama、LM Studio 或云端服务，见 模型设置。

4. 写下第一章

  1. 左侧栏切到 「写作」，在章节树里右键 →「新建章节」。
  2. 在正文里直接打字。输入 / 可以选标题、列表、引用等样式。
  3. 写到段落末尾停一下，光标后会出现灰字：Tab 接受，Esc 放弃，继续打字也等于放弃。
  4. 点顶栏的「参考面板」，在 「本章」里能看到摘要、出场设定和设定建议。离开这一节或停笔两分钟后，摘要会在后台自己写好。

5. 接下来

  • 在 「设定库」建几张角色卡。正文里提到名字时会自动识别，鼠标停上去就能看卡片。见 设定库与大纲。
  • 按 ⌘/Ctrl+J 写一个情节点，让 AI 起一段草稿给你挑。见 写作与补全。
  • 了解稿件存在哪、怎么找回旧版本，见 文件、历史与导出。
